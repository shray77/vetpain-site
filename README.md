# Шкалы боли (vetpain-site) — CMPS-SF и FGS

Публичная витрина [shray77.github.io/vetpain-site](https://shray77.github.io/vetpain-site/) —
интерактивные шкалы острой боли из одобренного ТОП-списка научных идей
(`vet-digital-ideas.md`, идея №3): краткая композитная форма Глазго CMPS-SF
для собак и кошачья гримас-шкала FGS. Отдельная репа-сайтик — открывать
проще, чем обновлять APK.

## Что внутри

- `index.html` — витрина: два опросника (голос B «Формуляр», живой балл,
  порог анальгезии, протокол частоты оценки) + методология с историей,
  порогами и честными ограничениями (голос A «Периодика»).
- `painscales.js` — математическое ядро без DOM: структуры обеих шкал
  (дескрипторы — ранги 0..N-1; CMPS-SF 4+5+5+6+5+5 = 30 дескрипторов,
  макс. 24/20; FGS 5 юнитов × 0–2, макс. 10), scoring с омиссией
  мобильности (→ /20, порог 5 вместо 6) и ратио-нормализацией FGS
  (ISFM-2022), CJK-детектор данных.
- `tests/painscales.test.mjs` — гейт известных ответов: структура шкал
  (число дескрипторов на категорию, ранги), максимумы, границы порогов
  (5/24 ↔ 6/24, 4/20 ↔ 5/20, 3 ↔ 4 из 10), ратио-нормализация,
  мусорный ввод, самопроверка детектора.
- `tests/thresholds.reference.json` — референс порогов (паттерн
  tokens.json-verify): дрейф чисел = красный CI.
- `vet-ds.css` + `fonts/` + `fonts.css` — копия ядра ДС (синкер
  `vet-ds/scripts/sync.py`, реестр адопций).

## Методика (в двух словах)

- **CMPS-SF (собаки).** Шесть поведенческих категорий (A: вокализация,
  внимание к ране; B: мобильность — может быть пропущена при переломах
  позвоночника/таза/конечностей; C: реакция на пальпацию — 6 дескрипторов;
  D: состояние и поза), дескрипторы ранжированы, балл = сумма рангов.
  Максимум 24 (20 без B). Порог анальгетического вмешательства —
  **6/24 или 5/20** (WSAVA Guidance). Порядковая шкала: помощник
  клинического суждения, не замена.
- **FGS (кошки).** Пять юнитов мимики (уши, глазная щель, морда,
  вибриссы, голова) по 0/1/2, максимум 10; неоцениваемый юнит
  пропускается, итог нормализуется: ратио = сумма / (2 × оценённые).
  Порог спасительной анальгезии — **≥4/10** (WSVA/WSAVA cats),
  ратио-порог **≥0.4/1.0** (ISFM-2022). Стресс и седация искажают
  мимику — оценивать спокойную кошку до манипуляций.

## Гейты

```
node --test tests/painscales.test.mjs   # известные ответы + verify порогов
```

CI (`.github/workflows/ci.yml`) гоняет то же на каждый пуш. Дизайн —
через общие гейты vet-ds (`contrast_v2.py`, `a11y_gate.py`,
`character_gate.py`, `codegen.py --verify`, реестр `sync.py`).

## Приватность

Считает в браузере, ничего не отправляет; работает с диска (file://).
Вычисления локальны — открытая вкладка считает и без сети; повторное
открытие офлайн не гарантируется (сервис-воркера нет, спасает только
кэш GitHub Pages на ~10 минут).

## Дисклеймер

Обучающий инструмент: балл — индикатор обсуждения анальгезии, не диагноз
и не назначение; ни одно животное не должно остаться без анальгезии
из-за «маленького» балла. Шкалы принадлежат разработчикам (Университет
Глазго — CMPS-SF; Evangelista, Steagall и соавторы — FGS), витрина —
некоммерческая образовательная реализация со ссылками на первоисточники.
